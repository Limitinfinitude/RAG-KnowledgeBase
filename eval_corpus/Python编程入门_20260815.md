# Python 编程语言入门简介

## 一、变量与数据类型
Python 中的变量无需显式声明类型，赋值即创建。常见内置类型包括：
- 整数 int：如 `x = 10`
- 浮点数 float：如 `y = 3.14`
- 字符串 str：如 `name = "Alice"`
- 布尔值 bool：如 `flag = True`
- 列表 list、元组 tuple、字典 dict、集合 set

## 二、函数定义
使用 `def` 关键字定义函数：

```python
def greet(name):
    """返回问候语"""
    return f"Hello, {name}!"
```

函数支持位置参数、关键字参数、默认参数和可变参数（`*args`、`**kwargs`）。

## 三、面向对象
使用 `class` 定义类，支持继承、多态、封装：

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        raise NotImplementedError

class Dog(Animal):
    def speak(self):
        return "汪汪"
```

## 四、常用标准库
- os：操作系统接口
- sys：系统参数与函数
- json：JSON 数据处理
- re：正则表达式
- datetime：日期时间处理

## 说明
Python 是一种解释型、动态类型、面向对象的高级编程语言，由 Guido van Rossum 于 1991 年发布，以其简洁易读的语法和丰富的生态著称，广泛应用于 Web 开发、数据科学、人工智能等领域。
