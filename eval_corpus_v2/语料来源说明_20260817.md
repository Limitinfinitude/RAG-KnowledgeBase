## 评测集设计（104 条：85 正 + 19 负）

- **正样本**：每领域 6-11 条，覆盖事实型（数字/参数）、概念型（原理/定义）、程序型（怎么做）、赏析型（为什么好）四种问法；含跨域双相关样本（如「睡眠如何影响肌肉恢复」关联运动+睡眠两文档）。
- **陷阱负样本（6 条）**：跨领域词共现但语料无对应内容（如「心肺复苏的唐诗描写」「图书馆有咖啡的书吗」），考察检索系统能否在词面高度重叠时拒绝召回。
- **纯负样本（13 条）**：语料完全无对应内容的领域（黑洞、量子、潜水、宋代瓷器等），考察跨域误召回。

## 使用方法

```bash
# 重建评测库（删除旧库后）
python scripts/build_eval_kb_20260815.py --user 99
# 检索评测（向量 / 混合 / 生产形态重排三模式）
python scripts/eval_retrieval.py --user 99 --k 5 --mode all
# 端到端 LLM-as-judge 评测（RAGAS 风格）
python scripts/eval_e2e_ragas_style.py --user 99 --sample 24
```

历史评测原始输出：`docs/eval_raw_20260817.txt`（含 20260815 语料时期的对照数据）。
