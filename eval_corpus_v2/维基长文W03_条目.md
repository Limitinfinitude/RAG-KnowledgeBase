# 条目

铃木SX4（スズキ・SX4）为日本铃木公司自2006年起开发制造的紧凑型跨界休旅车，第一代之兄弟车为Fiat Sedici。 关于车名SX4，乃是「Sports X-over 4 all seasons（适合四季使用的运动型跨界休旅车）」之缩写。 历史 第一代（2006年-2014年） 2005年 - 12月1日在日本公开发表，并同日于欧洲开始生产；2006年日内瓦车展正式面世。此车款与义大利飞雅特汽车合作开发，并由义大利设计-乔治亚罗公司负责设计，故与Fiat Sedici同为兄弟车，但后者仅限欧洲市场销售。外型方面，车头蜂巢式水箱护罩两端向上拉出A柱折线，车侧的低腰线搭配大片窗户及车顶置物架，刻意外张的车轮拱让车尾较为肥厚，整体融合了越野风格。内装部分除了6/4分离后座座椅，亦提供两段式前翻分离座椅、后椅背完全收纳等变化设计，可满足不同需求调整空间变化。 采用TECT高刚性车体结构的底盘与第二代铃木Swift相同，但因车高较高，在弯道中重心转移的状况颇为严重，连带影响后轮的稳定性。悬吊系统采用欧系车常见的前麦花臣、后拖曳臂之设计，至于动力心脏因应各地市场的不同需求： * 欧洲：1.6L直列四缸DOHC M16A型引擎、2.0L直列四缸DOHC J20A型引擎、1.9L直列四缸共轨直喷D19A型涡轮增压柴油引擎 * 北美洲：2.0L直列四缸DOHC J20A型引擎 * 日本：1.5L直列四缸DOHC M15A型引擎、2.0L直列四缸DOHC J20A型引擎 * 台湾、中国：1.6L直列四缸DOHC M16A型引擎 * 印尼：1.5L直列四缸DOHC M15A型引擎 同年11月19日在中国北京国际车展公开原厂代号YY5的三厢轿车版并命名为「天语SX4」，以填补铃木Liana的产品空缺；11月28日开始在长安铃木下线生产。除了多出第三厢的车尾配置，1.6L直列四缸DOHC M16A型引擎也因应当地交通情况重新调校，最大马力108hp / 5,500rpm，峰值扭力为14.6kg·m / 3,500-4,500rpm；且提供五速手排与四速自排两种变速箱。长安铃木更为了中国的消费需求，提供米色双彩内装；高端车款更配备了六具安全气囊、防锁死煞车系统、EBD煞车力道分配系统、顶级CD音响与恒温空调系统等配置。 2006年 - 4月开始在美国、加拿大市场开卖，日本当地于7月4日上市，台湾则在同年12月推出。台湾市场之版本包含双前座SRS辅助气囊、车门辅助气囊与前后车窗辅助气囊等六颗安全气囊，再加上安全带自动紧缩装置及束力限制机构，保障驾驶者的安全。另外，ABS防锁死煞车系统、EBD煞车力道分配系统、16吋五幅式铝合金轮圈、音响快拨键、恒温空调系统、keyless无钥匙启动系统等亦为全车系标准配备。 2007年 - 印度马鲁蒂铃木公司开始投产三厢轿车式SX4，一开始1.6L直列四缸DOHC M16A型引擎并没有VVT可变汽门正时机构，后来才加入此机构。2010年8月该公司推出CNG天然气装置套件，2011年2月则推出1.3L直列四缸DOHC Multijet型柴油引擎版本。 2009年 - 美国市场推出「iAWD」四轮驱动车型，提供三种驱动方式：2WD前轮驱动、AWD AUTO四轮驱动、AWD LOCK四轮驱动。其中后者在时速超过每小时64公里可以启动，电子式限滑差速器采取前轴50%、后轴50%的传动比例。 2010年 - 实施小改款，北美洲式场新增六速手排变速箱，以及搭配CVT变速系统的2.0L直列四缸DOHC J20B型引擎，最大马力148hp / 6,000rpm；同时新增巡航定速系统、ESP称车身动态稳定系统等配备。台湾市场也在2013年推出小改款，重新注入家族设计的U字形车头设计，使得从车头看A柱折线更为明显。 燃料电池汽车SX4-FCV 铃木公司以SX4为基础，开发出以燃料电池作为动力来源的「SX4-FCV」，并于2008年6月24日取得国土交通大臣认定。这辆车最高时速可达每小时150公里，续行距离为250公里，并装置可回收输出能量的蓄电电容器。 竞速赛事 2006年3月铃木公司在日内瓦车展上宣布铃木世界拉力车队将投入2007年度世界拉力锦标赛，并公开其参赛概念车型式；这辆车乃由田嶋伸博率领的铃木运动公司（IRD公司前身）负责设计。2007年2月开始在日本分站下场测试，至于砂石路测试则是同年4月在法国南部进行。接著在科西嘉岛分站中，法国籍赛车手Nicolas Bernardi（Nicolas Bernardi）和领航员让-马克·福廷（Jean-Marc Fortin）驾驶SX4 WRC实际下场比赛；该队亦派出芬兰籍Sebastian Lindholm（Sebastian Lindholm）和领航员托米·图奥米宁（Tomi Tuominen）参加英国分站比赛。 2007年12月17日该车队宣布2008年度的比赛中，将由稻垣秋介取代原技术主管米歇尔·南丹（Michel Nandan）的职务，川田辉担任车队经理，赛车手则为芬兰籍Toni Gardemeister（Toni Gardemeister）、瑞典籍沛尔-贡纳尔·安德森等二人。由于错误的头段橡胶垫导致引擎故障，安德森在蒙地卡罗分站获得第8名，加德迈斯特则在瑞典分站获得第7名。后来，两辆车在墨西哥分站双双退出比赛。接著在纽西兰分站赛事中，安德森拿到第6名、加德迈斯特为第7名。日本分站里两人则各进步一名，甚至在札幌巨蛋举办的超级特殊赛程中，加德迈斯特替该车队夺下第一个获胜。在英国分站中，安德森获得第5名，加德迈斯特则是第7名。 可惜的是，受到金融海啸的冲击，2008年12月15日该车队宣布暂时退出2009年度WRC赛事。 这部为了参加美国派克峰国际爬山赛而特别打造的特制赛车，设计者与赛车手皆为田嶋伸博。动力心脏为3,071c.c.水冷式V型6缸DOHC引擎，在双涡轮增压器的加持下，可输出910bhp / 8,750rpm的最大马力和90.5kg-m / 5,850rpm的扭力峰值。为了轻量化，车体总重量刻意压低至1,100公斤。果然2011年6月26日田嶋创下9分51秒278的记录，打破自己于2007年7月21日驾驶铃木运动XL7爬山赛特制车（Suzuki Sport XL7 Hill Climb Special）所创的10分1秒408的旧记录。 第二代（2013年-2021年） 2012年 - 9月铃木公司先是在巴黎车展发表名为「S-Cross」的概念车设计图，翌年3月日内瓦车展复公开量产车型。原厂接受顾客的心声反应，将车身尺码从次紧凑型（B segment）放大至紧凑型（C segment），轴距亦达到2,600mm；不过高度降低20mm，行李厢容量增至430公升。动力心脏视市场特性及需求而定，共有1.5L直列四缸DOHC VVT M15A型引擎、1.6L直列四缸DOHC VVT M16A型引擎、2.0L直列四缸DOHC J20A型引擎、1.6L直列四缸DOHC DDiS型柴油引擎等四种；变速箱则有五或六速手动排档、四速自动排档、CVT等设定。欧洲地区自2013年秋季开始由马札尔铃木公司供应，翌年5月亦开始由金铃汽车引进台湾，然而这款车将不会在北美洲市场上市。 2013年 - 12月23日长安铃木正式推出大改款的SX4，并命名为「铃木锋驭」。动力来源和上一代同样为1.6L直列四缸DOHC VVT M16A型引擎，搭配五速手排或可模拟七速的CVT手自排变速箱。依照FF或4WD驱动方式、变速箱设定以及配备的不同，区分成五种车型。 2014年 - 5月在台湾正式上市，名为「SX4 Crossover」。标准配备为7具SRS辅助安全气囊、ABS防锁死煞车系统、EBD电子制动力分配系统、EBA刹车辅助系统、ESP车身动态稳定系统、HHC斜坡起步辅助系统、方向盘换档拨片及音响快拨键、巡航定速系统、keyless无钥匙启动系统等，动力心脏和上一代同样为1.6L直列四缸DOHC VVT M16A型引擎，可输出最大马力118hp / 6,000prm、最大扭力15.9kg-m / 4,400rpm，搭配可模拟七速的CVT手自排变速箱。 2015年 - 9月29日SX4获得好设计奖，同时该公司的第八代铃木Alto/第三代铃木Alto Lapin、第六代铃木Every/第三代Every Wagon、第四代铃木Solio/第二代Solio Bandit也一同获奖。 2016年 - 8月10日印尼市场发表小改款的「SX4 S-Cross」，最明显的差异在于水箱罩改采二条镀铬横条，而动力换成1.5L直列四缸DOHC VVT M15A型引擎，可输出109ps / 6,000rpm的最大马力、138N·m / 4,400rpm的最大扭力。 2017年 - 4月19日开幕的上海车展上，原厂发表小改款的SX-4，并取名为铃木骁途。车头改采直瀑式镀铬前格栅，配合熏黑LED头灯和LED日行灯。动力心脏新设1.4L直列四缸DOHC缸内直喷K14C-DITC型涡轮增压引擎，与第四代铃木Escudo相同。配合5速手排或CVT变速箱，可输出最大马力140ps / 5,500rpm、最大扭力22.4kg·m / 1,700-4,000rpm。同年6月15日，日规小改款亦正式发售。全车在匈牙利马札尔铃木公司制造，采进口方式引入日本。虽然沿用原1.6L直列四缸DOHC VVT M16A型引擎，但改为六速自动排档。车头改成直瀑式镀铬前格栅、熏黑LED头灯、LED日行灯、LED尾灯、17吋新样式铝合金轮圈，并新增绀青色、红色等车身涂装。 同年6月15日日本引进匈牙利马札尔铃木公司制造的小改款，同样把车头改成直瀑式镀铬前格栅，并熏黑LED头灯、LED日行灯、LED尾灯、17吋新样式铝合金轮圈，新增绀青色、红色等车色，共计4种车身涂装。同年7月21日台湾金铃汽车引进小改款SX4，同样由马札尔铃木公司在匈牙利制造，搭载1.4L直列四缸DOHC缸内直喷K14C-DITC型涡轮增压引擎，配合附换档拨片的6速手自排变速箱。在行车安全防护方面，具备TECT车体、7具SRS安全辅助气囊、ESP车身动态稳定系统、HHC斜坡辅助系统、ABS/BA/EBD三合一煞车辅助系统、TPMS胎压侦测系统等配备。
